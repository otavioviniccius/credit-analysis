# 📌 Credit Risk Decision API

Sistema completo de análise de crédito para concessão de cartão.

## 🚀 Funcionalidades

- **Feature Engineering**  
  Preparação e transformação de variáveis para melhor desempenho do modelo.

- **Machine Learning (Logistic Regression)**  
  Modelo estatístico para prever probabilidade de inadimplência.

- **Probabilidade de Inadimplência**  
  Cálculo da chance de um cliente não cumprir suas obrigações financeiras.

- **Política de Decisão**  
  - Aprovar  
  - Restrito  
  - Negado  

- **Cálculo de Limite de Crédito**  
  Definição automática do limite com base no perfil do cliente.

- **API com FastAPI**  
  Interface REST para integração com outros sistemas.

- **Testes Automatizados (pytest)**  
  Garantia de qualidade e confiabilidade do código.

- **Estrutura Modular (src layout)**  
  Organização clara e escalável do projeto.
